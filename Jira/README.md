## 🛠️ General Prerequisites
To perform these practicals independently, students require:
1. A computer (macOS, Windows, or Linux) with Google Chrome, Edge, Safari, or Firefox.
2. A reliable internet connection.
3. A Google account (Gmail) to authenticate with Atlassian Cloud.
4. Access to Atlassian Jira Cloud (Free Tier is sufficient for all 7 practicals).

## 📖 Standard Structure of Each Practical
Every practical document is structured independently so it can be performed standalone:
1. **Practical Number and Title**
2. **Objective**
3. **Requirements**
4. **Procedure** (Sequential steps with Step Number, Navigation, Action, and Expected Result)
5. **Verification**
6. **Troubleshooting**
7. **Result**
8. **Viva Preparation** (3–5 interview/examination Q&As)
9. **Practical Checklist**
